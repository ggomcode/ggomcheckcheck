# NEIS 생활기록부 XLS 파일 구조 및 파싱 규격

나이스(NEIS)에서 다운로드한 **.xls** 형식의 학교생활기록부(창체, 세특, 행특) 데이터 파싱 및 분석 규격 정리 문서입니다.

---

## 1. 창체 (창의적 체험활동 상황) xls

### 가. 파일 확인 기준
* **D4 셀 (Row 4, Col D)**: `'학교생활기록부 창의적체험활동상황'` 텍스트 존재
* **B6 셀 (Row 6, Col B)**: 학년반 정보 존재 (예: `3학년 1반`) -> **현재 학년반**으로 인식

### 나. 학번 생성 규칙
* **B열 (Col B)**: 번호 (숫자)
* **현재 학번 (5자리)**: B6의 현재 학년반과 B열의 번호를 조합하여 5자리 숫자로 생성 (예: 3학년 1반 1번 -> `30101`)

### 다. 컬럼별 데이터 구조
* **C열 (Col C)**: 학생 이름 (`'성  명'` 또는 `'성명'`이 입력되어 있으면 표의 헤더임)
* **D열 (Col D)**: 이수학년 (숫자: 1, 2, 3 등)
* **E열 (Col E)**: 창체 영역 (`자율활동`, `동아리활동`, `진로활동`, `봉사활동` 중 1개)
* **G열 (Col G)**: 해당 이수학년 영역의 이수 시간 (숫자)
* **I열 (Col I)**: 해당 이수학년 영역의 특기사항 서술문
  * *단, 진로활동 중 I열의 값이 `'희망사항'`인 경우, **M열**에는 희망진로가 있고,바로 아래행의 I열이 특기사항임. (인접 컬럼 통합 파싱 필요)*
* **3개 학년 × 3개 영역 분리 필수**: 창체 데이터는 1학년, 2학년, 3학년 누적 데이터에 대하여 자율활동, 동아리활동, 진로활동 영역이 독립 레코드로 분리 감지되어야 함.

### 라. 표 헤더 및 페이지 꼬리말/나눔 구별
* **표 헤더 행**: B열에 `'번 호'`가 포함된 행과 그 다음 행까지 총 2개 행이 표 헤더임
* **페이지 꼬리말 행**: 
  * H열: 현재 페이지 번호 (숫자)
  * J열: `'/'`
  * K열: 전체 페이지 번호 (숫자)
  * N열: 학교 이름
  * 꼬리말 행의 2개 윗행까지가 해당 페이지의 특기사항 내용임
  * H열과 K열의 숫자가 같으면 마지막 페이지임
* **페이지 나눔 기준**: 꼬리말 행 + 1행까지가 해당 페이지 범위이며, **꼬리말 행 + 3행**부터 다음 페이지 표 헤더가 시작됨

## 2. 세특 (세부능력 및 특기사항) xls

### 가. 파일 확인 기준
* **H6 셀 (Row 6, Col H)**: `'학교생활기록부 세부능력 및 특기사항'` 텍스트 존재
* **B8 셀 (Row 8, Col B, 또는 B6~B8 범위)**: 학년반 정보 존재 (예: `3학년 1반`) -> **현재 학년반**으로 인식

### 나. 3개 사이클(섹션) 구조
1. **1번째 사이클 (`일반 영역`)**: 엑셀 파일 앞부분에 위치하며 1번~31번 학생의 일반 교과 세특 및 학년별 `개세특`이 배치됨.
2. **2번째 사이클 (`<진로 선택 과목>`)**: B열에 `<진로 선택 과목>` 구분이 등장하며 1번~31번 학생의 진로 선택 과목 세특이 배치됨. (`'과 목'` 컬럼 추가 삽입으로 컬럼 시프트 발생)
3. **3번째 사이클 (`<체육ㆍ예술>`)**: B열에 `<체육ㆍ예술>` 구분이 등장하며 1번~31번 학생의 체육/예술 과목 세특이 배치됨.

### 다. 학번 생성 규칙
* **B열 (Col B)**: 번호 (숫자)
* **현재 학번 (5자리)**: B8(또는 B6)의 현재 학년반과 B열의 번호를 조합하여 5자리 숫자로 생성 (예: 3학년 1반 1번 -> `30101`)

### 라. 컬럼별 데이터 구조
* **C열 (Col C)**: 학생 이름 (`'성  명'`은 표의 헤더임)
* **D열 (Col D)**: 이수학년 (숫자: 1, 2, 3 등)
* **F열 / H열 (Col F / Col H)**: 과목별 특기사항 및 개인별 세부능력 및 특기사항 내용 (진로선택/체육예술 섹션 시프트 포함 전수 파싱)

### 마. F열 과목명 및 서술문 파싱 규칙
1. **줄바꿈 및 문단 통합**: Alt+Enter(`\r\n`), 일반 엔터(`\n`), HTML `<br>` 태그 등 모든 형태의 줄바꿈 기호를 표준 줄바꿈으로 자동 통합 처리
2. **과목명 추출**: 문단 시작(또는 텍스트 내 패턴)이 `'한국사: '`처럼 시작되면 `:`를 제외한 `'한국사'`를 과목명으로 인식
3. **과목명 바이트 제한**: `:` 앞에 위치한 과목명은 띄어쓰기 포함 **30바이트 이하**여야 함 (30바이트 초과 시 과목명이 아닌 일반 특기사항 본문 내 콜론으로 처리)
4. **과목간 구분 (엔터 2번 vs 1번)**:
   * 엔터 2번(`\n\n`, 1행 빈 줄)으로 나뉘어진 문단은 **서로 다른 과목**으로 인식
   * 엔터 1번(`\n`)으로 줄바꿈된 문단은 **동일 과목 내 계속되는 내용**으로 인식
   * *예외*: `'(1학기)통합과학: '` 형태 이후 엔터 1번 후 `'(2학기)통합과학: '` 형태가 나오는 경우 다른 과목으로 분리 인식
5. **개인별 세부능력 및 특기사항(개세특) 정밀 규격**:
   * `개세특`은 **1번째 사이클(일반 영역)**에서만 존재하며, 진로선택 과목 및 체육ㆍ예술 섹션에는 존재하지 않음.
   * 학년당 **최대 1개만** 존재 가능 (1학년 0~1개, 2학년 0~1개, 3학년 0~1개).
   * 각 학년의 **가장 마지막 과목명 문단**(예: 1학년 `기술·가정`, 2학년 `일본어Ⅰ`, 3학년 `교육학`)의 마침표 후 **`\n\n`(이중 줄바꿈)** 이 등장하고, 그 뒤에 시작하는 문단이 과목명 헤더(예: `과목명:`) 없이 시작하는 독립 문단일 때만 **`개세특`**으로 지정.
   * 학년 중간에 위치한 과목명 없는 문단은 `개세특`이 아니며 직전 과목의 계속되는 문장임.
   * 학년의 가장 마지막 문단이 과목명으로 끝나면 그 학년은 `개세특`이 없는 학생임.

6. **페이지 나눔(인쇄 경계) 시 문장 연결 및 개세특 판정 규칙**:
   * **페이지 나눔 여부 우선 판단**: 다음 페이지의 첫 문단이 과목명 없이 시작할 때, 이전 페이지 마지막 문장이 마침표 등 종결 부호 없이 끊겨 있다면(예: `...비교 분석하고 `, `...발표 시 신뢰감 있는 `) 이는 페이지 분할에 의한 것이므로 **앞 페이지의 문장에 반드시 이어붙여야 함**.
   * **2학년 사례**: 이전 페이지의 마지막 과목(`일본어Ⅰ`)이 미종결된 상태로 다음 페이지 첫 문단(`교육 제도가...`)으로 이어지는 경우, 첫 문단은 `일본어Ⅰ` 과목 본문으로 이어붙이며, 그 뒤 `\n\n` 이후에 등장하는 문단(`학교자율과정...`)을 2학년 `개세특`으로 인식.
   * **3학년 사례**: 마지막 과목(`교육학`) 아래 `\n\n` 이후 `학교자율과정...`으로 개세특이 시작된 후 페이지 나눔이 발생한 경우, 다음 페이지 첫 문단(`목소리와...`)은 미종결된 앞 페이지 개세특에 이어붙여 하나의 완전한 3학년 `개세특`으로 합성.

### 바. 표 헤더 및 페이지 꼬리말/나눔 구별
* **표 헤더 행**: B열에 `'번 호'`가 포함된 행과 그 다음 행까지 (2개 행)
* **페이지 꼬리말 행**:
  * K열: 현재 페이지 번호 (숫자)
  * L열: `'/'`
  * M열: 전체 페이지 번호 (숫자)
  * N열: 학교 이름
  * 꼬리말 행 2개 윗행까지가 해당 페이지 특기사항임 (K열 == M열 이면 마지막 페이지)
* **페이지 나눔 기준**: 꼬리말 행 + 3행부터 다음 페이지 표 헤더 시작 (꼬리말과 다음 페이지 헤더 사이의 공백 및 학년반 제목 행 스킵)

## 3. 행특 (행동특성 및 종합의견) xls

### 가. 파일 확인 기준
* **E4 셀 (Row 4, Col E)**: `'학교생활기록부 행동특성 및 종합의견'` 텍스트 존재
* **B6 셀 (Row 6, Col B)**: 학년반 정보 존재 (예: `3학년 1반`) -> **현재 학년반**으로 인식

### 나. 학번 생성 규칙
* **B열 (Col B)**: 번호 (숫자)
* **현재 학번 (5자리)**: B6의 현재 학년반과 B열의 번호를 조합하여 5자리 숫자로 생성 (예: 3학년 1반 1번 -> `30101`)

### 다. 컬럼별 데이터 구조
* **C열 (Col C)**: 학생 이름 (`'성  명'`은 표의 헤더임)
* **D열 (Col D)**: 이수학년 (숫자: 1, 2, 3 등)
* **E열 (Col E)**: 행동특성 및 종합의견 내용 (페이지 나눔이 없는 한 보통 1개 행으로 구성)

### 라. 표 헤더 및 페이지 꼬리말/나눔 구별
* **표 헤더 행**: B열에 `'번 호'`가 포함된 행과 그 다음 행까지 (2개 행)
* **페이지 꼬리말 행**:
  * G열: 현재 페이지 번호 (숫자)
  * H열: `'/'`
  * I열: 전체 페이지 번호 (숫자)
  * K열: 학교 이름
  * 꼬리말 행 2개 윗행까지가 해당 페이지 특기사항임 (G열 == I열 이면 마지막 페이지)
* **페이지 나눔 기준**: 꼬리말 행 + 3행부터 다음 페이지 표 헤더 시작

## 4. 페이지 나눔 경계 텍스트 결합 및 검증 처리

1. **문장 이어붙이기 규칙**:
   * 페이지가 바뀌는 지점에서 앞 페이지의 마지막 문장이 `.`(마침표)로 끝나지 않은 경우, 다음 페이지 첫 번째 문단과 문장이 계속 이어지는 것으로 판단하여 경계 텍스트를 자동 결합함.
2. **띄어쓰기 예외 처리**:
   * 페이지 나눔 결합 과정에서 발생하는 띄어쓰기 오차(예: 단어 결합부 공백 유무)는 AI 검증 시 오탈자/띄어쓰기 오류로 검출하지 않고 정상 처리함.

---

## 5. 예외 처리 및 잠재적 위험 방어 로직 (Edge Case Handling)

1. **본문 콜론(`:`)과 과목명 콜론 구별 강화**:
   * 본문 내 `1. 탐구 주제:`, `활동 결과:`, `느낀 점:` 등의 일반 콜론 문구는 30바이트 이하더라도 과목명으로 잘못 분류되지 않도록 제외 키워드 패턴 필터링을 적용함.
2. **개세특(개인별 세특) 오인식 예외 방어**:
   * 엔터 2번(`\n\n`)으로 구분된 마지막 문단이 독립된 개세특인지, 단순 한 과목의 2번째 문단인지 명확히 구별하기 위해 앞 문단의 마침표 완료 여부 및 과목명 헤더 부재 조건을 동시에 검증함.
3. **페이지 결합 시 마침표 오타 누락 차단**:
   * 앞 페이지 마지막 문장이 마침표(`.`) 없이 끝났더라도, 다음 페이지 첫 문단이 새로운 활동 시작 키워드(`(자율활동)`, `(동아리명)(16시간)`, `(1학기)과목명:`)로 시작할 경우 서로 다른 활동으로 처리하여 오결합을 차단함.
4. **HTML-XLS vs Binary XLS 파일 포맷 자동 호환**:
   * NEIS 시스템 다운로드 포맷(HTML 기반 `.xls` vs 표준 바이너리 `.xls`/`.xlsx`)에 구애받지 않도록 멀티 포맷 파서 로직(Fallback Engine)을 적용함.
5. **학년반 셀 위치 탐색 유연화**:
   * B6, B8 셀 좌표 고정 탐색 외에도 상단 10개 행 내 `X학년 Y반` 정규식 자동 탐색을 결합하여 서식 위치 미세 변경에 안전하게 대응함.
